📌 About

DreamNest is a full-stack property booking platform where users can:

✔ Register / Login
✔ List properties
✔ Browse listings
✔ Search by category & filters
✔ View property details
✔ Manage bookings, trips, wish lists, reservations

It’s designed for both travelers and hosts — inspired by modern, responsive travel apps.

🧩 Features
🔹 User

✔ Sign-up, Login
✔ View listings
✔ Search & filter properties
✔ Save favorites / wishlist
✔ Book properties

🔹 Host / Owner

✔ Create, edit & delete your own property listings
✔ Add photos & highlights
✔ Manage reservations

🔹 Common

✔ Full authentication & authorization
✔ Dynamic routes for listings
✔ REST API integration
✔ Responsive UI
